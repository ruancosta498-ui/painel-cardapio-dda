# Painel Cardápio DDA

Painel administrativo do cardápio da Delícia de Açaí.

## Stack

- React 19
- Vite 6
- JavaScript/JSX
- Lucide React
- Supabase client preparado para a próxima etapa

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

O projeto foi estruturado como uma aplicação Vite + React padrão para facilitar importação, desenvolvimento e preview em plataformas compatíveis, incluindo o fluxo de integração com GitHub do Lovable.

## Estado atual

A interface administrativa está pronta e, nesta etapa, os dados de produtos, categorias e adicionais ainda usam estado local do navegador. A integração com Supabase será feita na próxima etapa, antes de disponibilizar a edição persistente para o estabelecimento.
